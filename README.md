# Meal planner

A simple weekly meal planner and shopping list for the family, built to run on an iPhone home screen.

- `index.html`, `style.css`, `app.js` — the app (plain HTML/CSS/JavaScript, no build step)
- `sync.js` — optional sharing between phones via a Supabase database
- `recipes.json` — the recipes; edit this file to change meals
- `icon.png` — home-screen icon

It is hosted with GitHub Pages straight from the `main` branch. Any change pushed to `main` goes live within a minute or two.
